# JEAF Services API README #

This repository contains the source code of JEAF Launcher. JEAF Launcher is a very basic project that can be used to run Java applications as Windows executable or Service. JEAF Launcher also provides an mechanism for automatic updates.

## Links ##
For further information please refer to:

* [JEAF Launcher](https://anaptecs.atlassian.net/l/c/hMcbY6c4)
* [Maven Repository](https://search.maven.org/artifact/com.anaptecs.jeaf.launcher/jeaf-launcher-project)

## How do I get set up? ##

* Create a clone of this repository on your local machine.
* Execute Maven on the top level project `maven clean install`
